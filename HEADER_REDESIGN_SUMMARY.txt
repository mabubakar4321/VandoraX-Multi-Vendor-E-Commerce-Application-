## Technical Implementation

### HTML Structure
```html
<header style="background: white; ...">
  <div style="max-width: 1400px; ...">
    <div style="display: flex; ...">
      <!-- Logo -->
      <!-- Search Bar -->
      <!-- Icons (Wishlist, Cart) -->
      <!-- User Menu / Auth Buttons -->
    </div>
  </div>
</header>
```

### Dynamic Elements

**Cart Count Badge:**
```javascript
fetch('{{ route('cart.count') }}')
  .then(r => r.json())
  .then(data => {
    document.getElementById('cart-count').textContent = data.count;
    document.getElementById('cart-count').style.display =
      data.count > 0 ? 'block' : 'none';
  })
```

**Wishlist Count Badge** (Authenticated Users Only):
```javascript
@if(auth()->check())
fetch('{{ route('wishlist.count') }}')
  .then(r => r.json())
  .then(data => {
    // Update badge with count
  })
@endif
```

### Responsive Design
- Mobile (320px): Full-width header, stacked layout if needed
- Tablet (768px): Optimized spacing
- Desktop (1024px+): Full horizontal layout, max-width 1400px
